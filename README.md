# Claw-bot-

# How my code works (description)

My claw bot starts at the starting point with a closed claw. 
Then according to my code it opens 90 degrees and the arm lifts 90 degrees with it.
Then it drives forwards 675mm and closes the claw 90 degrees grabbing the block and then
it reverses a couple cm and takes a 180 degree turn goes forwards 670 then the arms goes
90 degrees down and opens the claw placing the blocks.
